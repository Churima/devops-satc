# devops-satc
Matéria DevOps

O que é DevOps:
DevOps é uma cultura e conjunto de práticas que unem Desenvolvimento (Dev) e Operações (Ops) para entregar software de forma mais rápida, confiável e contínua.

🎯 Objetivo
Reduzir o tempo entre escrever código e colocá-lo em produção, mantendo qualidade e estabilidade.

🔑 Principais pilares
Integração Contínua (CI) – código é integrado e testado frequentemente.
Entrega/Implantação Contínua (CD) – deploy automatizado e frequente.
Infraestrutura como Código (IaC) – servidores e redes definidos por código.
Automação – testes, build, deploy e monitoramento automatizados.
Colaboração – times trabalham de forma integrada (menos “silos”).

🛠 Ferramentas comuns
CI/CD: Jenkins, GitLab
Containers: Docker
Orquestração: Kubernetes
IaC: Terraform

Monitoramento: Prometheus

👉 Resumo: DevOps é mais sobre cultura + automação + colaboração para acelerar entregas com qualidade.

O que é SRE:
SRE (Site Reliability Engineering)

SRE é uma prática criada pelo Google que aplica princípios de engenharia de software para resolver problemas de operações e confiabilidade.

🎯 Objetivo
Garantir que sistemas sejam confiáveis, escaláveis e disponíveis.

🔑 Conceitos principais
SLO (Service Level Objective) – meta de confiabilidade (ex: 99,9% de uptime).
SLI (Service Level Indicator) – métrica que mede desempenho (latência, erro).
Error Budget – margem aceitável de falhas.
Automação pesada – reduzir trabalho manual (toil).
Observabilidade – métricas, logs e tracing.

👉 SRE foca muito em estabilidade, métricas e confiabilidade mensurável.
